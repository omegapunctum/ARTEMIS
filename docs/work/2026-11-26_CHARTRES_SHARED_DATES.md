# Шартрский собор — проба общего представления датировок

Исследовательская сверка от 26 ноября 2026 года. Вопрос — можно ли представить шесть записей CONTINUUM в одной карточке ARTEMIS с сохранением смысла каждой даты?

## Сверка идентичности

В экспорте [Features](../../data/features.json) на ревизии `08b18f0736a84faecab95e02ab94883ba136309e` идентификатор `dc4b7dde-e7b6-4a71-8bf2-0b7056266635` встречается у одного объекта. В редакционной таблице CONTINUUM шесть строк указывают на этот объект. Множество обратных ссылок совпало в обоих направлениях. При повторной обработке тех же строк по их исходным идентификаторам осталось шесть записей. Эта проверка выполнялась в памяти.

## Что показывать исследователю

| Предмет утверждения | Как читать дату | Корректное отображение |
|---|---|---|
| Пожар романского собора | Июнь 1194, в хронологии собора указан день 10 июня | Событие у предшествующего здания |
| Перестройка основного корпуса | 1194 — около 1230 | Полоса работ с приблизительным окончанием |
| Богослужения в новом хоре | В 1221 использование уже засвидетельствовано | Отметка свидетельства. Начало использования неизвестно |
| Три фронтона | 1245–1250 | Работы над частями здания |
| Освящение | 17 октября 1260 | Событие с точностью до дня |
| Северный шпиль | 1506–1513 в хронологии. 1507–1513 в пресс-досье | Две версии начала с раздельными ссылками |

Основания — [хронология собора, разделы XII–XVII веков](https://www.cathedrale-chartres.org/cathedrale/monument/lhistoire/les-grandes-dates/) и [пресс-досье, страница 10 PDF](https://www.cathedrale-chartres.org/wp-content/uploads/2024/09/Dossier-de-presse-Millenaire.pdf). Оба издания принадлежат собору. Точность источника сохраняется даже при годовом масштабе просмотра.

## Вывод для передачи данных

Для карты получился один объект с шестью записями контекста, для шкалы — три периода и три датированные отметки. В выгрузке старой карточки сохранено окончание 1252. В рассмотренных источниках основание для применения этой даты к основному корпусу не установлено.

Для следующей пробы экспорта требуется отдельно передавать предмет работ, временную роль, исходную точность и источник каждого варианта. Иначе производный интерфейс может представить 1221 как первое богослужение или выбрать единственный год начала строительства шпиля. Сверка охватывает один объект. Работа двух производственных экспортёров, перенос данных в общую базу и понимание карточки посетителями остаются открытыми.

## Пробный экспорт

Снимок шести строк находится в `fixtures/chartres_export/v1/claims.json`. В нём явно указаны предмет, роль даты, точность и ссылка для каждой альтернативы. Дневная точность пожара и освящения сверена с хронологией собора. Геометрия обозначает современный ориентир.

Из корня репозитория выполните `python scripts/export_chartres_pilot.py /tmp/chartres-export`. Файл `chartres.geojson` содержит один точечный объект с шестью утверждениями. Файл `chartres-timeline.json` содержит три периода и три отметки. Проверка `python -m pytest tests/test_chartres_export.py` перечитывает оба файла и сравнивает результаты повторного запуска. Подключение читательских интерфейсов к этим файлам остаётся отдельным этапом.
