## Shared interaction specification

1. Both public entry routes use the same composed bundle and application. `/globe/` remains the primary entry; `/region/` is a compatible initial-state/deep-link entry into that environment. `/atlas/` retains its existing compatibility runtime. Layer, time and object actions operate in the open document with the same MapLibre instance; no navigation, reload, `map.remove()` or dataset metadata replacement.
2. Three independent native layer controls: Leonardo, Roman Empire and Architecture references. Default Globe entry enables Leonardo and Roman layers at Range 1452–1519; Architecture starts off. Region entry starts in its native first period. Controls display bounded coverage and honest empty/outside-coverage state. Enabling a layer never silently changes time or camera. Explicit period/overview actions may change their named state.
3. One calendar selection and query apply across the composed input. The bounded CE year axis 91–1519 is the union of dated query coverage; it is not complete history or an architecture lifetime axis. Native year controls permit direct access across the long coverage gap. Original finer source dates remain preserved; year display does not create exact dates.
4. Range uses overlap for Leonardo and Roman native intervals. A wide Range may include records from different eras; label it as an interval collection, not simultaneous historical context. Multiple eligible Roman versions remain separate dated items with native interval labels and geometry identities; never union their shapes or describe them as one instantaneous border.
5. Scrub has one shared cursor across 91–1519. Roman territory evaluates at the cursor, not the accumulated past window. Leonardo retains its accepted accumulating trace from its native default origin 1452 (or a valid restored legacy origin within its coverage). **At cursor 100, the shared cursor stays 100, a matching Roman version may be visible, and Leonardo is empty/outside coverage. Do not clamp global time to 1452 or construct the reversed interval [1452,100].** The origin is an accumulation policy, not a second semantic clock.
6. Architecture references remain independent of selected historical time; show their atemporal role and unknown applicability while visible. Showing them with dated layers does not assert co-presence, encounter, relation, influence or historical existence.
7. Use one selection resolver and source/uncertainty inspector. Hide or clear a selection when its own layer/time result becomes hidden; changing another layer must preserve the selected object's disclosure. A single selection does not move the camera; explicit focus may do so. Route gaps stay null and chronology styling remains clearly non-route.
8. Shared URL/history restores active layers, calendar/mode, selection, language and Globe/2D presentation, plus valid renderer-local camera state. Preserve useful saved Leonardo `presence`/Range/Scrub links and Region preset/item links through explicit legacy translation; do not leak one domain's selection into another. Back/Forward restores the recorded workspace state without document navigation. Malformed input falls back deterministically without fabricated semantic values.
9. Preserve the incumbent dark map identity, native controls, source/status language and progressive disclosures. Provide EN/RU names, pressed/checked state, visible focus, ready/error states, measured overlay spacing, desktop/narrow layouts and accessible named controls. No new design system or heuristic visual CI.
